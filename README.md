# Brainwave Landing Page

![React](https://img.shields.io/badge/React-18.2-blue)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.3-purple)
![Vite](https://img.shields.io/badge/Vite-4.0-orange)
![License](https://img.shields.io/badge/License-MIT-yellow)

This is a modern and responsive **React Landing Page** built with **Tailwind CSS** and **Vite**. It features a clean and interactive design, perfect for showcasing products, services, or portfolios.

---

## Features

- **Responsive Design**:
  - Fully responsive layout for mobile, tablet, and desktop devices.
  - Built with **Tailwind CSS** for a modern and customizable UI.

- **Interactive Components**:
  - Parallax effects for a dynamic user experience.

- **Sections**:
  - **Hero Section**: A visually appealing introduction with a call-to-action.
  - **Features Section**: Highlights key features with icons and descriptions.
  - **Pricing Section**: Displays pricing plans with clear details.
  - **Footer**: Includes social media links and contact information.

- **Customizable**:
  - Easily customizable components and styles using Tailwind CSS.
  - Modular structure for adding or removing sections.

---

## Technologies Used

- **Frontend**:
  - React 18
  - Tailwind CSS
  - Vite (for fast development and builds)
    
- **Icons**:
  - React Icons

## Installation

### Prerequisites

- Node.js 16+
- npm or yarn

### Steps

1. **Clone the Repository**:
   ```bash
   git clone [https://github.com/AmrMohamed27/Brainwave-Clone]
   cd Brainwave-Clone
   ```
2. **Install Dependencies**:
   ```bash
   npm install
   # or
   yarn install
   ```
3. **Run the Application**:
   ```bash
   npm run dev
   # or
   yarn dev
   ```
